# Project-Specific Rules

- **Hạn chế chạy lệnh build/test khi chưa được cho phép**: Tuyệt đối không tự ý chạy các lệnh biên dịch hoặc chạy kiểm thử (như `dotnet build`, `dotnet test`,...) trừ khi được người dùng yêu cầu hoặc đồng ý trực tiếp, nhằm tiết kiệm thời gian.
- **Do not run build or test commands without explicit permission**: Never execute build or test commands (e.g., `dotnet build`, `dotnet test`) unless explicitly requested or approved by the user, to save time and avoid unnecessary processes.
